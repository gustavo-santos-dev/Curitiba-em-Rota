# 🌍 Curitiba em Rota

### Guia Turístico Interativo de Curitiba

O **Curitiba em Rota** é um projeto acadêmico desenvolvido com o objetivo de apresentar os principais pontos turísticos, parques, museus, atrações culturais e opções gastronômicas da cidade de Curitiba.

O site oferece uma experiência interativa, permitindo que os visitantes explorem diferentes destinos, organizem roteiros e planejem seus passeios.

## 💻 Tecnologias utilizadas

- HTML5 — estruturação das páginas
- CSS3 — estilização e responsividade
- JavaScript — interatividade e funcionalidades
- Bootstrap — componentes e recursos de interface
- GitHub Pages — hospedagem do site

## 🚀 Funcionalidades

- Navegação entre 10 páginas
- Exploração de parques e pontos turísticos
- Filtros por categorias
- Sistema de favoritos
- Sugestões e organização de roteiros turísticos
- Checklist de viagem
- Calculadora de gastos
- Informações sobre cultura, gastronomia e hospedagem
- Formulários interativos
- Integração com Google Maps
- Conteúdos multimídia com vídeo e áudio
- Layout adaptado para diferentes tamanhos de tela

## 🎯 Objetivo do projeto

Aplicar na prática os conhecimentos adquiridos durante a graduação em Análise e Desenvolvimento de Sistemas, desenvolvendo uma aplicação web com foco em organização de código, interface, navegação e experiência do usuário.
